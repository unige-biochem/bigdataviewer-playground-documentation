# Commands Reference

This section provides tutorial-style documentation for BigDataViewer Playground commands, organized by functionality.

BigDataViewer Playground provides a rich set of commands accessible through Fiji's menu system. These commands allow you to create viewers, manage sources, apply transformations, and much more.

## How to Access Commands

All BigDataViewer Playground commands are available through:
- **Fiji Menu**: `Plugins > BigDataViewer-Playground > ...`
- **Search Bar**: Press `L` in Fiji and type the command name
- **Scripts**: Commands can be called programmatically from Groovy, Python, or other scripting languages
