About BigDataViewer Playground
==============================

BigDataViewer Playground is an extension built on top of `BigDataViewer <https://imagej.net/plugins/bdv/>`_, the powerful multi-dimensional image viewer for `ImageJ <https://imagej.net/>`_ and `Fiji <https://fiji.sc/>`_. It extends BigDataViewer's capabilities by providing additional tools for manipulating, processing, and analyzing large-scale image data directly within the Fiji ecosystem.

Whether you're working with 2D images, 3D volumes, time-series data, or multi-channel acquisitions, BigDataViewer Playground integrates seamlessly with existing ImageJ/Fiji workflows while leveraging BigDataViewer's efficient handling of terabyte-scale datasets.

Key Features
------------

* **Built on BigDataViewer**: Leverages the proven BigDataViewer framework for efficient multi-resolution image handling
* **Fiji integration**: Works natively within Fiji, complementing existing plugins and workflows
* **Multi-dimensional visualization**: View 2D, 3D, multi-channel, and time-series images
* **Large dataset support**: Handle gigabyte and terabyte-sized datasets efficiently through lazy loading
* **Interactive exploration**: Navigate through your data with intuitive controls
* **Processing capabilities**: Apply filters, transformations, and analysis tools
* **Format compatibility**: Support for various image formats including BDV-compatible formats (HDF5, N5, OME-Zarr)
